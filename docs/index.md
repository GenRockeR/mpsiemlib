# mpsiemlib

Неофициальный SDK для работы с MP SIEM через API. В SDK используется как UI API,
так и прямые вызовы к микросервисам вследствие того, что UI API имеет ряд ограничений.

## Поддерживаемые версии

MP SIEM R26.0.x - R27.6.x

## Основные функции

1. Unit-тесты для проверки совместимости с новыми версиями MP SIEM.
2. Аутентификация с Core, KB (в том числе по PAT-токену).
3. Журналирование и его настройка.
4. Хранение параметров и передача модулям.
5. Работа с активами.
6. Работа с событиями через API.
7. Работа с фильтрами событий и белыми списками.
8. Работа с инцидентами.
9. Работа с табличными списками.
10. Работа с контентом в KB (включая базы контента и ревизии).
11. Работа с задачами сбора.
12. Работа со встроенным мониторингом SIEM и источников.
13. Работа с пользователями и ролями в IAM.
14. Работа с макросами и конвейерами.

## Сетевой доступ и права

Для работы SDK необходимы следующие сетевые разрешения:

- MP Core: tcp 443
- MP Marketing Core: tcp 3334
- PT KB: tcp 8091
- Storage (Elasticsearch, для модуля `Events`): tcp 9200

SDK аутентифицируется в Core, PT KB, PT MC. Ряд функций требует
административной учетной записи в IAM, PT KB, SIEM.
